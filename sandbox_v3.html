🏛️ Security Architecture Reference

Upload Guards

  • Whitelist: .html / .htm only
  • Max 2 MB per file, rejected client + server
  • MIME double-check (not extension only)
  • BOM / encoding strip before parsing
  • Filename sanitized (no path traversal)

XSS / Injection Guards

  • Detect & flag external <script src>
  • Flag eval(), Function(), setTimeout(str)
  • Block document.cookie, localStorage
  • Block window.parent / window.top
  • CSP: connect-src 'none' stops all fetch/XHR

Sandbox Isolation

  • allow-scripts only (no allow-same-origin)
  • No access to parent DOM or cookies
  • referrerpolicy="no-referrer"
  • Preview uses Blob URL (no real path exposed)
  • Disposed after preview session

Distribution Security

  • Signed token URL, expires in 15 min
  • RBAC: only approved roles download
  • OS auto-detected, correct binary served
  • HTML source never exposed in binary
  • Audit log: who downloaded, when
