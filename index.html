Map 🏛️ Security Architecture

Upload

  • HTML + assets (images, PDF, CSS, JS)
  • 10 MB total bundle limit
  • Assets inlined as data URLs before sanitization
  • Filename sanitized — no path traversal

XSS / Injection

  • External <script src> detected and flagged
  • eval(), Function(), setTimeout(str) flagged
  • All on* inline handlers stripped
  • javascript: and vbscript: URLs stripped
  • connect-src 'none' — no outbound requests

Sandbox Isolation

  • allow-scripts only — no allow-same-origin
  • No access to parent DOM or cookies
  • referrerpolicy="no-referrer"
  • Preview via Blob URL — real path not exposed

Distribution

  • Signed token URL, expires in 15 min
  • RBAC — approved roles only can download
  • HTML source never exposed in the binary
  • Audit log on every approval and download
